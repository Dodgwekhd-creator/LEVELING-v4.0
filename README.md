# LEVELING (v4.0)

A cognitive training engine and procedural puzzle web application built as a self-contained single-file HTML5, CSS3, and Vanilla JavaScript application.

## Live Demo
Play it directly in your browser: [https://dodgwekhd-creator.github.io/LEVELING-v3.2/](https://dodgwekhd-creator.github.io/LEVELING-v3.2/)

## Features
* **Adaptive Protocol (Infinite Procedural Mode):** Dynamically scales across 12 procedural Practice archetypes spanning Tiers 1–5 in **Spatial Transformation**, **Working Memory**, **Deductive Logic**, and **Pattern & Math**.
* **Paradox Core (Campaign Mode):** 20 structured 10-question Campaign levels (200 puzzles) across Acts I–IV testing cognitive reflection, probability paradoxes, syllogisms, and lateral reasoning.
* **The Crucible (Error-Recovery Queue):** Automatically captures missed or revealed problems so you can re-attempt and clear them.
* **Skill Profile & Streak System:** Tracks accuracy across all four cognitive domains alongside a daily 3-puzzle goal, streak flame, and earnable Freeze Shields.
* **Zero Dependencies:** Runs natively in any modern browser without build tools or frameworks, with 1-click JSON backup export and import.
